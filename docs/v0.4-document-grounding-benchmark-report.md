## 1. Executive Summary

As established in [`docs/v0.4-root-cause-audit.md`](file:///c:/oloric%20v01/oloric-model/docs/v0.4-root-cause-audit.md), the original 20-item evaluation benchmark (`evaluation/benchmark.jsonl`) contains 0 items requiring document grounding. Every item uses a generic template for `selected_text` (`"The concept of X is fundamental to understanding..."`) and tests other pedagogical dimensions (hints, analogies, concrete examples, numerical examples). Consequently, the document grounding score of 1.15/4 measured in v0.3 was largely an artifact of benchmark design rather than an accurate reflection of model capabilities.

To resolve this limitation for OLORIC v0.4 evaluation, we have constructed and validated a dedicated supplemental benchmark:
`evaluation/benchmark_docground_v1.jsonl`

### Key Properties
- **Exact Size**: Exactly 25 examples (`dg_v1_001` through `dg_v1_025`).
- **5 Behavior Classes**: 5 examples per class, balanced across domains.
- **Realistic Context**: Every example contains genuinely quotable excerpts, realistic academic formulas and parameters, clear learner states, and explicit expected grounded behaviors.
- **Zero Leakage**: 0 duplicate IDs, 0 student prompt matches, and 0 target response matches against the frozen `evaluation/benchmark.jsonl` (20 items) or `data/generated/oloric_v03_dataset.jsonl` (480 records).
- **Schema Validated**: 100% compliant with `OloricModelInput` and `OloricModelOutput` Pydantic schemas.

## 2. Benchmark Design Rationale

The benchmark addresses the three primary failure modes identified during the v0.3 root-cause audit:

| Audit Finding | Benchmark Design Countermeasure |
|---|---|
| **DG-1: Benchmark Gap** (0/20 original items tested document grounding) | 25 dedicated items where the primary task instruction and scoring criteria center strictly on `document_grounded` behavior. |
| **DG-2: Unquotable Selected Text** (Template string prevented citation) | Every item provides a realistic textbook excerpt with specific definitions, data points, or mechanical formulas suitable for direct quotation or paraphrase. |
| **DG-3: Lack of Edge Case Supervision** (Conflict handling & hallucination refusal unrepresented) | Specific behavior classes for detecting document conflicts (Class D) and refusing to invent unsupported data (Class E). |
