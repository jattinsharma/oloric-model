# Baseline Semantic Evaluation Report

## Overview
This report summarizes the manual semantic evaluation of 40 baseline responses generated by `Qwen3-4B-Instruct-2507` across both General (20) and Structured (20) modes. The evaluation assesses pedagogical effectiveness, factual correctness, and structural adherence using an 11-dimension rubric.

## Executive Summary
While the baseline model demonstrates strong foundational factual correctness and good linguistic simplicity, it fundamentally acts as a **"helpful encyclopedic assistant" rather than an adaptive tutor**. It struggles significantly with pedagogical strategy selection, contextual adaptation, and action obedience.

---

## 1. General Mode Analysis

**Strengths:**
*   **Factual Correctness (Avg: 3.8/4):** The model rarely hallucinates facts and provides accurate domain knowledge.
*   **Simplicity (Avg: 3.6/4):** Language is well-calibrated for beginners, avoiding unnecessary jargon.

**Weaknesses:**
*   **Strategy Adherence (Avg: 2.3/4):** The model heavily favors "explaining from scratch." Even when explicitly asked for hints, practice problems, or follow-up questions, it defaults to a lecture format first.
*   **Context Retention (Avg: 1.5/4):** The model frequently ignores provided document evidence. More critically, it ignores prior conversation history, failing to adapt when prior hints fail or when erroneous context is present.
*   **Prerequisite Detection (Avg: 1.6/4):** The model rarely scaffolds weak prerequisites implicitly, often asking questions that presuppose the missing knowledge.

---

## 2. Structured Mode Analysis

**Strengths:**
*   **Schema Validity:** As verified by the automated checks, the model perfectly adheres to the basic JSON structure.
*   **Memory Candidate Quality (Avg: 3.4/4):** When the model generates a memory candidate, it is usually concise, accurate, and well-anchored to the concept.
*   **Diagnostic Quality (When Attempted):** When forced into the `diagnose` action, the model asks reasonably good questions.

**Weaknesses:**
*   **Action Collapse:** The model overuses the `"explain"` action, applying it to tasks meant for `hint`, `practice`, or `misconception_correction`.
*   **Understanding Check Depth (Avg: 2.5/4):** Many understanding checks are trivial rote-recall questions ("What did I just say?") rather than application or transfer questions.
*   **Numerical/Concrete Generation:** The model struggles to generate genuinely numerical examples in the structured schema, heavily preferring qualitative descriptions.

---

## Conclusion & Next Steps
The baseline model is capable of generating structured JSON and factually accurate text, but it lacks the pedagogical nuance required for OLORIC. It acts like an encyclopedia rather than a tutor. 

The QLoRA fine-tuning phase must focus on:
1.  **Behavioral Cloning of Tutoring Strategies:** Forcing the model to use hints, Socratic questions, and diagnostics instead of defaulting to explanations.
2.  **Contextual Awareness:** Training the model to recognize and react to prior conversation turns, especially failed attempts or misconceptions.
3.  **Strict Action Mapping:** Teaching the model the distinct boundaries between the JSON actions (e.g., `diagnose` vs `confirm_understanding` vs `explain`).

For a detailed breakdown of specific failure instances, refer to `failure_cases.md`.
